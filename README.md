# Kıyas

İş ilanını CV'lerinle karşılaştıran Chrome eklentisi. Hangi terim eksik, hangisi
CV'nde var ama geride kalmış — maddeler halinde söyler. CV'ne hiçbir şey eklemez,
uydurmaz; eksik bulduğu terimi "bunu gerçekten kullandın mı?" diye sorar.

**Gizlilik politikası:** https://kursaderen.github.io/kiyas/gizlilik.html

Eklentinin sunucusu yok. CV'lerin ve taradığın ilanlar tarayıcından çıkmaz.
İsteğe bağlı AI katmanı kullanıcının kendi API anahtarıyla çalışır; istek
doğrudan seçilen sağlayıcıya gider.
